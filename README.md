# PWM Motor Control

Проєкт на базі **ESP32-S3** для керування швидкістю двигуна постійного струму залежно від освітленості, яку вимірює фоторезистор (LDR). Двигун керується через транзистор **2N2222A**. Задум полягає в тому, щоб змінювати швидкість двигуна відповідно до показань LDR за допомогою PWM.

## Поточний стан

Зараз прошивка зчитує LDR, згладжує показання ковзним середнім і вмикає або вимикає GPIO 17 за порогами. PWM і плавне регулювання швидкості ще не реалізовані. Тобто швидкість двигуна поки не змінюється пропорційно освітленості.

## Робота прошивки зараз

1. ESP32-S3 зчитує аналоговий сигнал LDR на GPIO 2 кожні 20 мс.
2. Для згладжування використовується середнє останніх 8 вимірювань.
3. Якщо середнє значення нижче `THRESHOLD_DARK` щонайменше 500 мс, GPIO 17 переходить у HIGH.
4. Якщо значення вище `THRESHOLD_LIGHT` щонайменше 500 мс, GPIO 17 переходить у LOW.
5. Між порогами попередній стан двигуна зберігається. Дані виводяться в Serial Monitor кожні 500 мс.

Поточна логіка передбачає, що менше значення ADC відповідає темряві, а більше — світлу. Це залежить від того, як LDR підключений у дільнику напруги.

## Підключення

- Плата: ESP32-S3 DevKitM-1.
- LDR підключений як дільник напруги, його середня точка — до GPIO 2 (ADC).
- GPIO 17 керує базою 2N2222A через резистор.
- Двигун підключається до джерела живлення через 2N2222A за схемою низькобічного ключа.
- З’єднайте землю ESP32 і джерела живлення двигуна.
- Підключіть захисний діод паралельно двигуну з правильною полярністю.

Не підключайте двигун безпосередньо до GPIO ESP32. Перевірте, що струм двигуна відповідає можливостям транзистора, і використовуйте окреме живлення двигуна.

## Налаштування

Параметри задаються на початку `src/main.cpp`:

| Параметр | Значення | Призначення |
| --- | ---: | --- |
| `LDR_PIN` | 2 | Аналоговий вхід LDR |
| `MOTOR_PIN` | 17 | Вихід керування 2N2222A |
| `THRESHOLD_DARK` | 1800 | Нижній поріг показань ADC |
| `THRESHOLD_LIGHT` | 2200 | Верхній поріг показань ADC |
| `FILTER_SIZE` | 8 | Кількість показань у ковзному середньому |
| `ADC_INTERVAL_MS` | 20 мс | Інтервал зчитування LDR |
| `CONFIRM_TIME_MS` | 500 мс | Час підтвердження умови перед зміною стану |
| `PRINT_INTERVAL_MS` | 500 мс | Інтервал виведення даних у Serial Monitor |

Пороги потрібно налаштувати за фактичними показаннями LDR. Щоб швидкість двигуна змінювалася зі світлом, прошивку потрібно доповнити PWM-керуванням і перетворенням показання ADC на коефіцієнт заповнення PWM.

## Збірка та прошивання

Відкрийте проєкт у VS Code з розширенням PlatformIO або встановіть PlatformIO Core. З кореня проєкту виконайте:

```sh
pio run
pio run --target upload
pio device monitor --baud 115200
```

Налаштування середовища PlatformIO містяться у `platformio.ini`.

## Serial Monitor

Приклад поточного виводу:

```text
ADC raw: 2048 | ADC avg: 2012 | Motor: OFF | Pending: NO
```

`Pending: YES` означає, що порогова умова виникла й прошивка очікує завершення часу підтвердження.
